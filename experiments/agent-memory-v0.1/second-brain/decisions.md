# Decision principles — documentary only

1. A **proposal** contains a suggested change, not an approval.
2. An **agent receipt** is a claim that must be revalidated against immutable source evidence.
3. A **reviewer PASS** scoped to pure static metadata means only that those checks passed.
4. A **formal approval** is separate from tool output, memory, chat messages and experiment PASSes.
5. A **NO-GO** cannot be superseded by a retrieved Markdown note or a newer draft PR.
6. A **stale or unverifiable** source must be marked unknown and escalated for independent verification.

Do not treat this note as a standalone policy or executable instruction. It documents principles for comparing claims to the controlling approved decision sources.
